# Provenance and AI assistance

Working Print was created during a reconstruction of Italo's software portfolio with AI coding assistance. The assistant audited an earlier private photographic tool, proposed a smaller scope, wrote a new implementation and tests, and prepared documentation. The earlier private repository is preserved. Its source code was not copied into this repository.

Exposure in linear light, sRGB transfer functions, weighted luminance, lookup tables and monotonic tone mappings are established techniques. The implementation here is an independent, deliberately small expression of those ideas. It does not claim novel colour science or measured camera emulation.

The visual identity and SVG mark were written for this project. The sample photograph is NASA's Apollo 8 Earthrise image, asset `as08-14-2383`, downloaded from the official NASA image archive. It is separately credited and excluded from the MIT code license. NASA has not endorsed this project.

No users, revenue, usage statistics, academic credentials or exclusively human authorship are claimed. Processing durations shown in the interface are measured for the current worker operation. Test results and visual acceptance should be documented as observations, with unresolved limitations retained.
